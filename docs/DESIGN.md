# 2027 플래너 설계

아이패드 홈 화면에 아이콘으로 올려 쓰는 개인용 웹 플래너. cafe24 호스팅에 배포한다.
디자인 시안: https://claude.ai/artifact/46D641RVLct9AugeTaRBqm

## 1. 범위

| 구분 | 내용 |
|---|---|
| 화면 | 연간, 월간, 주간 (세 가지뿐) |
| 기능 | 일정, 할 일, 의견, 손글씨 메모 |
| 달력 규칙 | 한 주는 주일(일요일)에 시작. 주일·공휴일 빨강, 토요일 파랑 |
| 사용 기간 | 2027년 1월부터. 연도 제한 없이 계속 사용 |
| 사용자 | 본인 1명 (비밀번호 로그인) |
| 기기 | 아이패드 가로 화면 기준. 세로와 PC 브라우저에서도 열림 |

## 2. 손글씨 메모 저장 방식

이미지로 저장하지 않는다. 펜이 지나간 좌표를 **획(stroke) 데이터**로 저장하고, 열 때마다 캔버스에 다시 그린다.

- 획 하나 = 색, 굵기, 점 목록 `[x, y, 필압]`
- 용량이 PNG보다 훨씬 작고, 확대해도 깨지지 않는다
- 획 단위로 지우기와 되돌리기가 된다
- 필요하면 그 자리에서 PNG로 내보낼 수 있다 (공유용)

손글씨는 페이지에 붙는다. 페이지 키 예: `year:2027`, `month:2027-01`, `week:2027-01-03`(그 주의 주일 날짜).

정렬 유지: 각 페이지를 1366×1024 논리 좌표로 고정하고 화면 크기에 맞춰 통째로 확대·축소한다. 좌표는 논리 좌표로 저장하므로 기기나 회전이 달라져도 글씨가 칸에서 어긋나지 않는다.

입력 구분: Pointer Events의 `pointerType`으로 나눈다. 애플 펜슬(`pen`)은 항상 쓰기, 손가락(`touch`)은 누르기와 넘기기. 별도 "쓰기 모드" 전환이 필요 없다.

## 3. 구성

```
아이패드 Safari (홈 화면에 추가 → 전체 화면 실행)
  └─ 정적 파일: index.html, app.js, app.css, manifest.json, 아이콘
       └─ 기기 안 저장소 (IndexedDB): 오프라인에서도 열리고 쓰기 가능
            └─ 동기화 ⇅  cafe24: PHP API + MySQL
```

- 프런트: 빌드 도구 없는 순수 HTML/CSS/JS. FTP로 올리면 끝난다.
- 서버: cafe24 웹호스팅 기본 제공인 PHP + MySQL(MariaDB).
- 홈 화면 아이콘: `manifest.json`, `apple-touch-icon`, `apple-mobile-web-app-capable` 메타 태그.
- 오프라인: 서비스 워커로 화면 파일을 캐시하고, 변경분은 온라인이 되면 서버로 보낸다. 충돌은 나중에 쓴 쪽이 이긴다 (혼자 쓰므로 충분).
- HTTPS 필수 (서비스 워커와 로그인 쿠키 때문). cafe24 무료 SSL 사용.

## 4. 데이터

| 테이블 | 주요 칸 |
|---|---|
| `events` 일정 | id, title, date_start, date_end, time_start, time_end, all_day, category(설교/예배/심방·미팅/개인), repeat_rule(없음/매주/매월/매년), alarm(없음/정시/10분 전/1시간 전/하루 전), memo, updated_at, deleted |
| `todos` 할 일 | id, title, due_date, done, done_at, sort, updated_at, deleted |
| `opinions` 의견 | id, content, source(누가·어디서), heard_on, status(새 의견/검토 중/반영/보류), memo, updated_at, deleted |
| `ink` 손글씨 | page_key, strokes(JSON), updated_at |
| `holidays` 공휴일 | date, name (설·추석 등 음력 공휴일과 대체공휴일 포함, 연 1회 갱신) |

`updated_at`과 `deleted`는 동기화용이다.

## 5. API (PHP)

| 경로 | 용도 |
|---|---|
| `POST /api/login.php` | 비밀번호 확인, 장기 세션 쿠키 발급 |
| `GET /api/sync.php?since=시각` | 그 시각 이후 바뀐 모든 항목 받기 |
| `POST /api/sync.php` | 기기에서 바뀐 항목 올리기 |
| `GET/PUT /api/ink.php?page=키` | 페이지 손글씨 읽기·저장 |
| `GET /api/ics.php?token=비밀키` | 일정을 `.ics`로 내보내기 (iPad 캘린더 구독용). 일정마다 알림(`VALARM`)을 함께 넣는다 |

## 5-1. 알림과 iPad 캘린더 연동

웹앱은 iPad의 캘린더·미리알림 앱을 직접 읽거나 쓸 수 없다. 서버를 거쳐 연동한다.

- **캘린더 구독 (1차)**: 서버가 `ics.php`로 일정을 내보내고, iPad 설정에서 "구독 캘린더"로 한 번 추가한다(`webcal://도메인/api/ics.php?token=...`). 일정이 캘린더 앱에 보이고, **알림은 캘린더 앱이 iPad에서 직접 울린다.** 플래너 → 캘린더 한 방향이며 갱신이 늦을 수 있다.
  - 주소에 긴 임의 토큰을 넣어 다른 사람이 일정을 보지 못하게 한다. 토큰은 설정에서 재발급한다.
  - 반복 일정은 `RRULE`로, 알림은 `VALARM`으로 내보낸다.
- **일정별 "캘린더에 추가"**: 일정 상세에서 `.ics` 한 건을 내려받아 iPad 추가 화면을 연다.
- **앱 안 알림 표시**: 오늘 일정 배너와 아이콘 배지는 앱을 열었을 때 보이게 한다.
- **웹 푸시 (2차)**: 홈 화면 앱 + 권한 허용 + 서버 cron이 필요하다. cafe24 호스팅에서 1분 단위 cron이 되는지 확인한 뒤 추가한다. 안 되면 외부 cron 서비스로 PHP 주소를 호출한다.
- **미리알림 앱**: 할 일은 플래너 안에서만 관리한다. 연동하려면 CalDAV 서버(sabre/dav)가 필요하고 호스팅 가능 여부 확인이 먼저다. 지금은 범위에서 뺀다.

## 6. 화면

공통 상단 바: 제목과 이전/다음/오늘 · 연간/월간/주간 전환 · 펜/지우개/되돌리기 · 일정 추가.

- **연간**: 12달 미니 달력, 주요 일정 날짜 표시, 올해 주요 일정 목록, 연간 메모(손글씨). 달을 누르면 월간으로.
- **월간**: 큰 달력에 일정 칩. 오른쪽에 할 일과 의견. 날짜를 누르면 일정 등록.
- **주간**: 주일~토 7칸. 일정 아래 빈 공간에 손글씨. 아래에 이번 주 할 일과 메모(손글씨).
- **일정 등록**: 제목, 날짜, 시작/종료, 분류, 반복, 알림, 메모. 한 화면에서 끝낸다.

## 7. 구현 순서

1. 화면 골격과 달력 계산 (연간·월간·주간, 2027년부터)
2. 일정·할 일·의견 등록과 기기 안 저장
3. 손글씨 (펜슬 입력, 획 저장, 지우개, 되돌리기)
4. cafe24 서버: DB, 로그인, 동기화
5. 홈 화면 아이콘, 오프라인, 공휴일 데이터
6. 캘린더 구독(`ics.php`)과 알림 설정
7. (조건부) 웹 푸시. cafe24 cron 가능 여부 확인 후

## 8. 모션과 터치 반응

원칙: 하루 수십 번 쓰는 화면이므로 움직임은 최소로, 반응은 즉각적으로 한다.

| 대상 | 처리 |
|---|---|
| 손글씨 | 애니메이션 없음. 펜슬 움직임을 바로 그린다. `pointermove`의 묶음 이벤트(`getCoalescedEvents`)와 `requestAnimationFrame`으로 지연을 줄이고, 캔버스에 `touch-action: none`을 준다 |
| 연간/월간/주간 전환 | 즉시 전환. 연속으로 누르는 동작이라 효과를 넣지 않는다 |
| 이전/다음 (달·주 넘기기) | 150ms 안의 짧은 좌우 이동과 페이드(`ease-out`). 넘어가는 방향이 보이게 하는 용도 |
| 버튼·칩·할 일 체크 | 누르는 동안 `scale(0.97)`, 160ms `ease-out`. 눌렀다는 느낌을 주는 유일한 효과 |
| 할 일 완료 | 체크 표시와 취소선만 바뀐다. 색상 전환 150ms |
| 일정 등록 시트 | 아래에서 올라오며 `translateY(100%)`→0, 약 250ms, `cubic-bezier(0.32, 0.72, 0, 1)`. 닫을 때는 더 빠르게(약 180ms) |
| 일정 저장 후 | 칩이 `scale(0.95)`+투명에서 150ms로 나타난다 |

- `transition: all`은 쓰지 않고 `transform`, `opacity`, `background-color`만 지정한다.
- 아이패드는 터치 기기라 hover 효과는 `@media (hover: hover) and (pointer: fine)` 안에서만 쓴다. 손가락이 닿았을 때 hover가 남지 않게 한다.
- `prefers-reduced-motion`이면 이동 효과는 빼고 페이드만 남긴다.
- 모든 누를 곳은 44px 이상. 연필로 쓰다가 손바닥이 닿는 문제는 `pointerType`으로 손가락 입력을 무시해 막는다 (쓰는 중에는 터치 입력 잠금).

## 9. 정해야 할 것

- "의견 관리"의 뜻: 시안은 **다른 분들에게 들은 의견·건의를 기록하고 처리 상태를 관리**하는 것으로 잡았다. 본인 생각·아이디어 노트라면 구성을 바꾼다.
- (확정) 일정 분류와 색: 설교 빨강, 예배 파랑, 심방·미팅 주황, 개인 그린
- 아이폰·PC에서도 같이 볼지 (동기화는 설계에 포함되어 있음)
- cafe24 호스팅 상품 이름과 cron(예약 작업) 사용 가능 여부 (웹 푸시 가능 여부를 가른다)
- 미리알림 앱 연동이 꼭 필요한지 (필요하면 CalDAV 검토)
