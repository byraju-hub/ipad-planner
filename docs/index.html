서버에 한 번 설치한 뒤 아이패드 홈 화면에 아이콘으로 추가합니다.

설치 파일 받기 (ZIP) GitHub에서 보기

1. 내 서버에 설치하기 처음 한 번만

준비물
  • PHP 8 이상과 MySQL(MariaDB)을 쓸 수 있는 웹 호스팅 (예: cafe24)
  • 호스팅의 FTP 접속 정보와 데이터베이스 이름·아이디·비밀번호
  • 내 컴퓨터에 설치된 Node.js 22 이상
  1. 1
    압축 풀고 준비하기

    위에서 받은 ZIP의 압축을 풀고, 그 폴더에서 터미널을 열어 아래 명령을 실행합니다.

    npm install
  2. 2
    접속 정보 파일 만들기

    폴더 안에 .env.deploy 파일을 만들고 내 호스팅 값으로 채웁니다. 이 파일은 Git에 올라가지 않으니 비밀번호가 공개되지 않습니다.

    FTP_HOST=ftp.내도메인.com
FTP_USER=내FTP아이디
FTP_PASS=내FTP비밀번호
DB_HOST=localhost
DB_NAME=내DB이름
DB_USER=내DB아이디
DB_PASS=내DB비밀번호
SITE_URL=https://내도메인.com/ip/
REMOTE_DIR=/www/ip
  3. 3
    설치하기

    화면을 만들어 서버에 올리고, 데이터베이스 표를 만들고, 관리자 비밀번호를 발급합니다. 비밀번호는 폴더의 .admin-password.txt에 저장됩니다.

    npm run deploy -- --setup
  4. 4
    로그인해서 확인하기

    SITE_URL 주소를 브라우저로 열고 발급된 관리자 비밀번호로 로그인합니다. 로그인한 뒤 설정에서 비밀번호를 바꾸세요.

나중에 고친 내용을 서버에 반영할 때는 npm run deploy만 실행하면 됩니다.

2. 아이패드 홈 화면에 올리기

  1. 1
    Safari로 열기

    아이패드 Safari에서 내 플래너 주소를 열고 로그인합니다.

  2. 2
    공유 → 홈 화면에 추가

    공유 버튼을 누르고 “홈 화면에 추가”를 고릅니다.

  3. 3
    아이콘으로 실행

    홈 화면의 아이콘을 누르면 주소창 없이 전체 화면 앱처럼 열립니다.
