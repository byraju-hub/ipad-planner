# iPad Planner

아이패드 홈 화면에 아이콘으로 올려 쓰는 개인용 웹 플래너. 애플 펜슬로 손글씨 메모를 할 수 있다.
2027년 1월부터 사용한다. 상태: **설계 완료, 구현 전**.

## 기능

- **세 가지 화면**: 연간 · 월간 · 주간 (한 주는 주일에 시작)
- **일정**: 설교(빨강) · 예배(파랑) · 심방·미팅(주황) · 개인(그린), 반복, 알림
- **할 일**과 **의견**(들은 건의와 처리 상태) 관리
- **손글씨 메모**: 이미지가 아니라 획(stroke) 데이터로 저장
- **오프라인 사용**과 서버 동기화
- **iPad 캘린더 구독**(`.ics`)으로 알림 수신

## 기술

| 구분 | 사용 |
|---|---|
| 화면 | Svelte 5, Vite (정적 빌드) |
| 서버 | PHP, MySQL (cafe24 웹호스팅) |
| 기기 저장 | IndexedDB, 서비스 워커 |

## 구조

```
src/    앱 (Svelte 컴포넌트, 손글씨 캔버스)
api/    PHP (login, sync, ink, ics)
docs/   설계 문서
```

## 배포

1. `npm run build`
2. `dist/`와 `api/`를 cafe24에 FTP로 업로드
3. iPad Safari에서 접속 → 공유 → **홈 화면에 추가**

## 문서

- [설계 문서](docs/DESIGN.md): 범위, 구조, 데이터, API, 화면, 구현 순서

## 구현 순서

1. 연간·월간·주간 화면과 달력 계산
2. 일정·할 일·의견 등록과 기기 저장
3. 손글씨 (펜슬 입력, 지우개, 되돌리기)
4. 서버: DB, 로그인, 동기화
5. 홈 화면 아이콘, 오프라인, 공휴일
6. 캘린더 구독과 알림
7. (조건부) 웹 푸시

> 이 리포지토리는 공개 상태다. 비밀번호, DB 접속 정보, 캘린더 구독 토큰은 올리지 않고 서버의 설정 파일에만 둔다.
