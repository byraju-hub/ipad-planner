# 아이패드 웹앱 플래너

아이패드 웹앱용 개인 플래너입니다. 아이패드 홈 화면에 아이콘으로 올려 앱처럼 쓰는 웹앱입니다. 연간, 월간, 주간 계획을 한눈에 보고, 애플 펜슬로 화면 어디에나 손글씨 메모를 남길 수 있습니다.

## 주요 기능

**세 가지 보기**
- 연간: 12달을 한 화면에서 보고, 일정이 있는 날에는 점이 표시됩니다.
- 월간: 날짜마다 일정이 보이고, 옆에서 할 일과 메모를 함께 관리합니다.
- 주간: 주일부터 토요일까지 일곱 칸으로 한 주를 봅니다.

한 주는 주일(일요일)에 시작합니다. 화면을 좌우로 밀면 이전·다음 주(달, 해)로 넘어갑니다.

**일정**
- 분류가 정해져 있고 이 순서로 표시됩니다: 설교(빨강), 교회(파랑), 부서(그린), 미팅(주황), 개인(보라)
- 종일 일정, 며칠에 걸친 일정, 매주·매월·매년 반복, 알림을 지원합니다.
- 주일과 공휴일은 빨간 글씨로 표시됩니다. 설날, 추석, 부처님오신날과 대체공휴일도 자동으로 계산합니다.

**할 일과 메모**
- 할 일은 기한을 정하거나 기한 없이 적어 두고, 체크로 완료 처리합니다.
- 메모는 들은 사람과 날짜를 적고, 새 메모 → 검토 중 → 반영 → 보류로 처리 상태를 관리합니다.

**손글씨 메모**
- 애플 펜슬로 연간·월간·주간 화면 어디에나 쓸 수 있고, 페이지마다 따로 저장됩니다.
- 색 세 가지, 지우개, 되돌리기가 있습니다.
- 펜슬을 쓰는 동안 닿는 손바닥은 무시합니다.

**어디서나 같은 내용**
- 인터넷이 없어도 열리고, 연결되면 서버와 자동으로 맞춰집니다.
- 일정을 아이패드 캘린더에 구독해서 캘린더 앱의 알림으로 받을 수 있습니다.
- 관리자 로그인이 있어 본인만 내용을 볼 수 있습니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 위쪽 | 지금 보는 기간, 이전·다음·오늘, 연간·월간·주간 전환, 펜 도구, 일정 추가, 설정 |
| 가운데 | 달력과 일정 |
| 옆·아래 | 할 일, 메모 |

## 설치

두 가지 방법이 있습니다.

**1. 설치 파일로 설치 (Node.js 필요 없음)**
1. [릴리스](https://github.com/byraju-hub/ipad-planner/releases/latest)에서 `ipad-planner.zip`을 받아 압축을 풉니다.
2. 폴더 안의 모든 파일과 폴더를 PHP 8 이상, MySQL(MariaDB)을 쓸 수 있는 웹 호스팅에 FTP로 올립니다.
3. 브라우저에서 올린 주소 뒤에 `install.php`를 붙여 열고, 데이터베이스 정보와 관리자 계정을 입력합니다. 끝나면 `install.php`는 저절로 지워집니다.

새 버전으로 바꿀 때는 새 ZIP의 파일을 같은 폴더에 덮어 올리면 됩니다. 데이터는 그대로 유지됩니다.

**2. 소스에서 직접 배포 (개발자용, Node.js 22 이상)**
1. `npm install` 후 `.env.deploy`에 FTP·데이터베이스 정보를 적습니다(Git에 올라가지 않습니다).
2. 처음에는 `npm run deploy -- --setup`, 이후에는 `npm run deploy`를 실행합니다.
3. 설치 파일(ZIP)은 릴리스를 만들면 GitHub Actions가 자동으로 만들어 붙입니다. 로컬에서 확인하려면 `npm run package`를 실행합니다(`release/` 폴더에 생성).

## 사용 환경

아이패드 Safari에서 열고 "홈 화면에 추가"를 하면 주소창 없이 앱처럼 실행됩니다. 2026년 11월부터 사용할 수 있고, 그 이후로는 끝 연도 제한이 없습니다.
