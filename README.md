# iPad Planner

아이패드 홈 화면에 아이콘으로 올려 쓰는 개인용 웹 플래너. 애플 펜슬로 손글씨 메모를 할 수 있다.
**2026년 11월 1일부터** 사용한다. 상태: **구현 완료(1~5단계)**, 배포 주소는 서버 설정에 따른다. 알림 배너와 웹 푸시는 아직 없다.

## 기능

- **세 가지 화면**: 연간 · 월간 · 주간 (한 주는 주일에 시작)
- **공휴일**: 설·추석·부처님오신날과 대체공휴일 자동 계산(2050년까지 한국 음력 자료 기준)
- **일정**: 설교(빨강) · 교회(파랑) · 심방·미팅(주황) · 개인(그린), 반복(매주·매월·매년), 알림
- **할 일**과 **의견**(들은 건의와 처리 상태) 관리
- **손글씨 메모**: 이미지가 아니라 획(stroke) 데이터로 저장. 연·월·주 페이지마다 따로
- **관리자 로그인**: 본인만 데이터에 접근
- **오프라인 사용**과 서버 동기화, 홈 화면 앱
- **iPad 캘린더 구독**(`.ics`): 설정 화면에서 주소 확인

## 기술

| 구분 | 사용 |
|---|---|
| 화면 | Svelte 5, Vite (정적 빌드) |
| 서버 | PHP, MariaDB (cafe24 웹호스팅), 테이블 접두어 `ip_` |
| 기기 저장 | IndexedDB, 서비스 워커 |

## 구조

```
src/    앱 (Svelte 컴포넌트, 달력 계산, 공휴일)
api/    PHP (login, sync, account, ics)
docs/   설계 문서
```

## 개발

```
npm install
npm run dev      # 개발 서버 (서버 없이 기기 안에서만 동작하는 개발 모드)
npm test         # 달력·공휴일·반복 일정 테스트
npm run build    # dist/ 생성
```

## 배포

1. 프로젝트 폴더에 `.env.deploy` 만들기 (FTP·DB 접속 정보. Git에 올라가지 않음. 항목: `FTP_HOST` `FTP_USER` `FTP_PASS` `FTP_PORT` `REMOTE_DIR` `SITE_URL` `DB_HOST` `DB_PORT` `DB_NAME` `DB_USER` `DB_PASS`)
2. 최초 1회: `node scripts/deploy.mjs --setup` (테이블 생성, 관리자 비밀번호 발급 → `.admin-password.txt`)
3. 이후: `npm run deploy` (빌드 후 `www/ip`에 업로드)
4. iPad Safari에서 접속 → 공유 → **홈 화면에 추가**, 로그인 후 설정에서 비밀번호를 바꾼다

## 구현 순서

1. ✅ 연간·월간·주간 화면과 달력 계산
2. ✅ 일정·할 일·의견 등록과 기기 저장
3. ✅ 손글씨 (펜슬 입력, 지우개, 되돌리기)
4. ✅ 서버: DB, 관리자 로그인, 동기화
5. ✅ 홈 화면 아이콘, 오프라인
6. 🔶 캘린더 구독·알림 필드 완료, 앱 안 알림 배너 미구현
7. (조건부) 웹 푸시

> 이 리포지토리는 공개 상태다. 비밀번호(해시 포함), DB 접속 정보, 캘린더 구독 토큰은 올리지 않고 서버의 설정 파일(`api/config.php`)에만 둔다.
